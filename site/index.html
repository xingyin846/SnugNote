这一版改了什么

  • 手机端界面跟着屏幕宽度自动缩放：窄屏自动变一列，宽屏自动加列，不再挤作一团。
  • 修好了手机上搜索框文字溢出的问题。
  • 右上角改成 ☰，可以按标签筛选便签（以前手机上找不到这个入口）。
  • 手机上每行两张便签，卡片与按钮一起缩小，单手更好按。
  • 桌面版外观没有变化。

安装说明

Windows

  1. 下载后双击运行，按向导下一步。
  2. 默认装在 %LOCALAPPDATA%\贴贴便签，也可自选目录。
  3. 若被安全软件拦下，选「允许」即可（自解压程序常被误报）。
  4. 卸载不会删数据，重新装回即恢复。

安卓

  1. 下载 APK 后点开安装。
  2. 提示「未知来源 / 外部来源应用」时允许安装。
  3. 装好后从桌面图标打开，不需要联网。
